# VLSFO Monitor · BAF Tracker

Dashboard giá VLSFO (Singapore / Rotterdam / Global 20) và phân tích BAF.

## 🔗 Xem dashboard live (GitHub Pages)

**https://bachhhhhhhhhhhhhh.github.io/themalaihay/**

> App chạy tại link GitHub Pages ở trên.

## Repo

- File chính: `index.html` (single-file app)
- Branch: `main`
- GitHub Pages: branch `main` → root `/`

## Tính năng

- Live ticker + chart cập nhật mỗi 1 giây
- Chuỗi giá neo theo Ship & Bunker (daily close)
- BAF impact, monthly compare, quant models
- Nguồn dữ liệu clickable (Ship & Bunker, Bunker Index, USDA, S&P)

## Chạy local

Mở `index.html` bằng trình duyệt, hoặc:

```bash
npx serve .
```
